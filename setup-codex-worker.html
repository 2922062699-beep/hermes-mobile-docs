Setup Codex Worker / 配置 Codex Worker

Last updated: 2026-06-11
Audience: users who want Hermes Mobile to send tasks from iPhone to PC-side Codex.

1. What This Is / 这是什么

Hermes Agent can spawn a Codex CLI subprocess for worker-style coding tasks. Hermes Mobile sends a run to Hermes Agent, and Hermes Agent starts Codex on the PC.

Hermes Agent 通过启动 Codex CLI 子进程来处理 Codex 任务。手机端不会直接运行 Codex；它只是把请求发给电脑端的 Hermes Agent。

2. Requirements / 前置要求

  • Hermes Agent is already installed and running. See Setup Hermes Agent.
  • Node.js 18 or later if installing Codex via npm. Download from nodejs.org.
  • An OpenAI API key from platform.openai.com/api-keys.
  • A dedicated local workspace directory for Codex file operations.

3. Install Codex CLI / 安装 Codex CLI

npm global install

npm install -g @openai/codex
codex --version

On this beta build, the verified local package is @openai/codex. If OpenAI publishes a newer installation method, follow the official Codex instructions for your platform.

Optional package manager commands such as Homebrew or winget may change. Use the npm command above unless your Codex distribution says otherwise.

4. Configure OpenAI API Key / 配置 OpenAI API Key

Windows PowerShell

$env:OPENAI_API_KEY = "sk-..."

macOS / Linux bash

export OPENAI_API_KEY="sk-..."

If you use a persistent Codex config file, verify it with your local Codex CLI documentation. For v1.0 beta, environment variables are the clearest path.

5. Configure Workspace / 配置工作目录

HERMES_MOBILE_WORKER_CWD controls the working directory used by Codex worker subprocesses. All file reads and writes happen from this directory.

Important v1.0 limitation: multiple mobile sessions share the same worker working directory. v1.1 will evaluate per-session workspace isolation. Do not point this to an important project root unless you understand the risk.

Windows PowerShell

New-Item -ItemType Directory -Force D:\hermes-worker-workspace
$env:HERMES_MOBILE_WORKER_CWD = "D:\hermes-worker-workspace"

macOS / Linux bash

mkdir -p "$HOME/hermes-worker-workspace"
export HERMES_MOBILE_WORKER_CWD="$HOME/hermes-worker-workspace"

6. Restart Hermes Agent / 重启 Hermes Agent

Restart Hermes Agent after setting OPENAI_API_KEY and HERMES_MOBILE_WORKER_CWD, so the worker subprocess inherits the environment.

7. Verify in Hermes Mobile / 手机端验证

  1. Open Hermes Mobile.
  2. Open the agent picker above the input bar.
  3. Select Codex.
  4. Send hello or please reply CODEX_OK.
  5. The reply should show the source label Codex.

8. Troubleshooting / 常见问题

codex command not found

Confirm codex --version works in the same terminal environment used to start Hermes Agent. If not, fix PATH or set the Codex command path in your Hermes Agent configuration.

Unauthorized

Check that OPENAI_API_KEY is present and valid for the account you intend to use.

Unexpected file behavior

Check HERMES_MOBILE_WORKER_CWD. Codex reads and writes relative to that directory.

9. Security Notes / 安全提示

  • Codex can read and write files in the configured workspace.
  • Do not put SSH keys, wallet files, browser profiles, or other sensitive data in the workspace.
  • Use a dedicated folder for Hermes Mobile worker tasks.
