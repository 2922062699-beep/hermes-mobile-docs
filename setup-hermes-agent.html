Setup Hermes Agent / 配置 Hermes Agent

Last updated: 2026-06-11
Audience: Hermes Mobile beta users who run their own PC backend.

1. What This Is / 这是什么

Hermes Agent is the PC-side backend used by Hermes Mobile. It provides an OpenAI-compatible Gateway API that Hermes Mobile can call from your iPhone.

Hermes Agent 是运行在电脑端的后端服务。Hermes Mobile 不托管你的聊天内容；手机会直接连接你自己电脑上的 Hermes Agent Gateway。

2. Requirements / 前置要求

  • Python 3.11 or later.
  • At least 4 GB free disk space.
  • An API key for an LLM provider, such as OpenAI, DeepSeek, or another OpenAI-compatible provider.
  • A separate HERMES_AGENT_API_KEY for Hermes Mobile to authenticate to your Gateway.

4. Install / 安装步骤

Windows PowerShell

cd C:\path\to\hermes-agent
py -3.11 -m venv venv
.\venv\Scripts\python.exe -m pip install --upgrade pip
.\venv\Scripts\python.exe -m pip install -r requirements.txt

macOS / Linux bash

cd /path/to/hermes-agent
python3.11 -m venv .venv
./.venv/bin/python -m pip install --upgrade pip
./.venv/bin/python -m pip install -r requirements.txt

If your Hermes Agent distribution provides a different installer, follow that installer first and then return to the verification section below.

5. Configure Agent API Key / 配置 Hermes Mobile 访问密钥

HERMES_AGENT_API_KEY is the key used by Hermes Mobile to access your Agent Gateway. It is not your OpenAI or DeepSeek key.

Windows PowerShell

$env:HERMES_AGENT_API_KEY = "replace-with-a-long-random-key"

macOS / Linux bash

export HERMES_AGENT_API_KEY="replace-with-a-long-random-key"

Configure your LLM provider key according to your Hermes Agent build. For example, an OpenAI-compatible build may require OPENAI_API_KEY or a provider-specific key.

6. Start Hermes Agent / 启动 Agent

Windows PowerShell

cd C:\path\to\hermes-agent
.\venv\Scripts\hermes.exe gateway run

macOS / Linux bash

cd /path/to/hermes-agent
./.venv/bin/hermes gateway run

The default Gateway port is 8642. Keep the terminal open while testing.

7. Verify / 验证

PowerShell

Invoke-WebRequest -UseBasicParsing http://127.0.0.1:8642/health

curl

curl http://127.0.0.1:8642/health

Expected response:

{"status":"ok"}

Some builds may also include a platform field, such as {"status":"ok","platform":"hermes-agent"}.

8. Troubleshooting / 常见问题

Port 8642 is busy / 端口被占

Stop the old Hermes Agent process or configure another port if your build supports it.

Missing package / 启动报缺包

Run the dependency installation step again inside the virtual environment.

Agent starts but /health is unreachable

  • Confirm the terminal process is still running.
  • Check whether another firewall or security tool blocks local TCP traffic.
  • Try http://127.0.0.1:8642/health on the PC first before testing from iPhone.
