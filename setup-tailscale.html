Setup Tailscale / 配置 Tailscale

Last updated: 2026-06-11
Audience: users who prefer a private mesh VPN instead of a public tunnel URL.

1. What This Is / 这是什么

Tailscale creates a private mesh VPN between your PC and iPhone. Hermes Mobile can then connect to the PC Hermes Agent through the PC's 100.x.x.x Tailscale IP address.

Tailscale 会在电脑和 iPhone 之间建立私有 mesh VPN。Hermes Mobile 可以通过电脑的 100.x.x.x Tailscale 地址访问 Hermes Agent。

2. Tailscale vs Cloudflare Tunnel

DimensionTailscaleCloudflare Tunnel
PrivacyPrivate mesh network with encrypted device linksHTTPS tunnel through Cloudflare edge
Mainland China accessDepends on account login path; Google login may be blockedUsually reachable directly in current beta tests
iPhone client requiredYesNo
Multiple devicesAutomatic meshSingle tunnel endpoint unless configured otherwise

3. Install on PC / PC 端安装

Windows

Download Tailscale for Windows: tailscale.com/download/windows.

After installation, log in and verify your PC IP:

& "C:\Program Files\Tailscale\tailscale.exe" ip -4

macOS

Download Tailscale for macOS: tailscale.com/download/mac.

tailscale ip -4

Linux

Use the official Linux installation guide: tailscale.com/download/linux.

tailscale ip -4

4. Install on iPhone / iPhone 端安装

  1. Install Tailscale from the iOS App Store.
  2. Log in with the same Tailscale account used on the PC.
  3. Keep Tailscale connected while using Hermes Mobile remotely.

iOS App link: Tailscale on the App Store.

5. Configure Hermes Mobile / 配置 Hermes Mobile

  1. Find the PC's Tailscale IP, for example 100.69.191.73.
  2. Use the Gateway URL format http://100.x.x.x:8642.
  3. Enter your Hermes Agent API Key.
  4. Connect from onboarding or Settings.

6. Verify / 验证

From the iPhone browser while Tailscale is connected, open:

http://100.x.x.x:8642/health

Expected result: a small page or JSON response showing status OK / Hermes Agent.

7. Troubleshooting / 常见问题

iOS login is blocked

If Google login is blocked in your region, try GitHub login or another supported login method.

100.x.x.x does not connect

  • Confirm Tailscale is connected on both PC and iPhone.
  • Confirm both devices are logged into the same Tailscale account or tailnet.
  • Run tailscale status on the PC if available.
  • Verify Hermes Agent is running at http://127.0.0.1:8642/health on the PC.

8. Known v1.0 Limitation / 已知 v1.0 限制

Settings test connection may be unstable for Tailscale URLs, similar to Cloudflare Tunnel URLs. If Settings fails but the iPhone browser can open /health, re-enter onboarding and configure the URL there. v1.1 will fix this flow.
