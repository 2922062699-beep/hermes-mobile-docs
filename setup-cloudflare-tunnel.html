Setup Cloudflare Tunnel / 配置 Cloudflare Tunnel

Last updated: 2026-06-11
Audience: users who want to reach their PC Hermes Agent from iPhone on 4G or another Wi-Fi.

1. What This Is / 这是什么

Cloudflare Tunnel can expose your local Hermes Agent Gateway through an HTTPS URL. This lets an iPhone reach the PC even when it is not on the same Wi-Fi.

Cloudflare Tunnel 可以把电脑本地的 Hermes Agent Gateway 暴露为一个 HTTPS 地址，让 iPhone 在 4G 或不同 Wi-Fi 下也能远程连接。

2. When to Use It / 适用场景

  • Personal remote access to your own PC Hermes Agent.
  • Temporary Demo Agent for App Store review.
  • Sharing a controlled beta environment with a trusted tester.

It is not ideal for latency-sensitive workloads or public services without additional hardening.

4. Mainland China Access Note / 中国大陆访问性说明

During 2026-06-11 testing, an iPhone on 4G could directly access a trycloudflare.com tunnel URL without VPN. Cloudflare edge locations observed during testing may include regions such as lax, hkg, or khh.

不同运营商和地区可能有差异。如果 4G 访问失败，请换网络、重启 tunnel，或改用 Tailscale / named tunnel。

5. Quick Tunnel / 临时 tunnel 完整步骤

Install cloudflared / 安装 cloudflared

Windows PowerShell

winget install --id Cloudflare.cloudflared

macOS

brew install cloudflared

Linux

Use the official Cloudflare package instructions: Cloudflare cloudflared downloads.

Start tunnel / 启动 tunnel

cloudflared tunnel --url http://localhost:8642

Copy the generated https://*.trycloudflare.com URL.

Configure Hermes Mobile / 配置 Hermes Mobile

  1. Open Hermes Mobile.
  2. Go to Settings or re-enter onboarding.
  3. Use the Cloudflare URL as the Gateway URL.
  4. Enter your Hermes Agent API Key.

6. Named Tunnel / 固定域名 tunnel

Named tunnel is recommended when you need a stable URL.

  1. Create a Cloudflare account: dash.cloudflare.com.
  2. Add your domain to Cloudflare.
  3. Create a tunnel in the Cloudflare Zero Trust dashboard.
  4. Install cloudflared on the PC.
  5. Configure ingress to forward your chosen hostname to http://localhost:8642.
  6. Run cloudflared as a service.

Official guide: Cloudflare Tunnel documentation.

7. Troubleshooting / 常见问题

cloudflared says no such host

Retry once and check DNS / IPv6 connectivity. Some networks need a second tunnel start.

iPhone gets timeout

Check 4G signal, restart the tunnel, or try again later. Cloudflare edge selection may vary.

Settings test fails but onboarding works

Known v1.0 limitation: Settings testConnection can be unstable for remote URLs. Re-enter onboarding and configure the Cloudflare URL there. v1.1 will fix this flow.

8. Security Notes / 安全提示

  • Anyone who knows a quick tunnel URL can reach the Gateway endpoint.
  • The Hermes Agent API Key is the main protection for your Gateway.
  • Do not post a trycloudflare.com URL publicly.
  • Stopping the cloudflared process immediately disconnects remote access.
