Hermes Mobile Privacy Policy

Last updated: 2026-06-10
Applies to: v1.0 and later
Contact: 2922062699@qq.com

1. Overview

Hermes Mobile is an iOS mobile control surface for a user-hosted Hermes Agent. The product is designed so that chat content, agent responses, API keys, and Gateway configuration remain under the user's control and are not routed through servers operated by the Hermes Mobile developer.

This policy describes how the Hermes Mobile App handles data. A user's self-hosted Hermes Agent, Bridge, VPN, Cloudflare Tunnel, or other network services may have separate data handling practices.

2. How We Collect and Use Data

2.1 Data the App Does Not Collect

Hermes Mobile does not send the following data to Hermes Mobile developer servers:

  • Chat content.
  • Agent responses.
  • Hermes Agent Gateway URL.
  • Agent API Key.
  • Bridge API Key.
  • Conversation history.
  • File or image attachment content.
  • Contacts, location, microphone data, or advertising identifiers.

Hermes Mobile does not use IDFA, does not perform advertising tracking, and does not sell user data.

2.2 Possible Anonymous Diagnostics

If a distributed build enables diagnostics provided by Apple, Expo, or the runtime platform, the following anonymous or low-identifiability data may be generated:

  • Crash logs.
  • Device model.
  • iOS version.
  • App version.
  • Performance or launch failure diagnostics.

This data is used only to diagnose crashes and improve app stability. It is not used for advertising tracking. If the final release build does not enable crash reporting, the App Store Connect App Privacy answers should reflect the actual release configuration.

3. Data Flow

3.1 Chat Data

When a user sends a message in Hermes Mobile, the request is sent directly from the iPhone to the Hermes Agent Gateway configured by the user. That Gateway typically runs on the user's own computer, local network, VPN, or user-managed HTTPS tunnel.

The Hermes Mobile developer does not proxy, store, or read this chat content.

Hermes Mobile stores necessary configuration and conversation data locally on the user's device to support session restore, history, and connection settings. Users can delete local iPhone data by uninstalling the app.

3.2 Remote Access

Users may choose LAN, Tailscale, Cloudflare Tunnel, or another self-managed network path to reach their Hermes Agent. These network paths are configured by the user and are subject to the user's own privacy and security choices.

If a user uses Tailscale, traffic is handled by the user's Tailscale network.

If a user uses Cloudflare Tunnel, Cloudflare may process connection metadata and handle HTTPS at its edge. This is not a service hosted by the Hermes Mobile developer.

4. Third-Party Services

Hermes Mobile uses or may interoperate with:

  • Expo / React Native, used to build the iOS app.
  • Apple iOS / App Store / TestFlight, used for installation, distribution, and system permissions.
  • Tailscale, an optional user-managed remote access network. It is not bundled with Hermes Mobile.
  • Cloudflare Tunnel, an optional user-managed HTTPS tunnel.
  • The user's own Hermes Agent, Hermes Mobile Bridge, and LLM provider.

These third-party services may have their own privacy policies. Users should review the services they choose for their network and agent deployment.

5. User Rights

Users can:

  • Uninstall Hermes Mobile to remove local app data from the iPhone.
  • Modify or clear Gateway URL / API Key settings in Hermes Mobile.
  • Clear or delete sessions, logs, and long-term memory from the PC-side Hermes Agent.
  • Remove network configuration from Tailscale, Cloudflare, or another third-party service they use.
  • Contact the developer at 2922062699@qq.com with privacy questions.

6. Security Measures

Hermes Mobile does not host the user's Agent service. Users are responsible for protecting:

  • Hermes Agent API Key.
  • Bridge API Key.
  • PC file system and project workspace permissions.
  • VPN / Tunnel access.
  • Long-term memory data.

Hermes Mobile separates temporary context for active chat sessions. Hermes Agent long-term memory may be used across sessions to provide continuity. Users can manage or clear long-term memory on the Hermes Agent side.

7. Children's Privacy (COPPA)

Hermes Mobile is intended for individual developers, researchers, and advanced users. It is not directed to children under 13. We do not knowingly collect personal information from children.

8. Policy Changes

We may update this policy as the app evolves. If data handling practices materially change, we will update the App Store listing, project documentation, or in-app privacy entry as appropriate.
