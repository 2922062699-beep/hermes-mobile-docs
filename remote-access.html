什么时候用哪个

  • 首次配置：先试 Cloudflare Tunnel（不需要 iPhone 装新 App）。
  • 隐私敏感场景：用 Tailscale（端到端加密）。
  • CF 边缘不稳定时：切换到 Tailscale 兜底。

常见问题

手机浏览器能打开 /health，但 Hermes Mobile 连接失败

v1.0 Settings 测试连接对远程 URL 可能不稳定。建议重新进入 onboarding，在引导页填写远程 URL 和 Agent API Key。

Cloudflare quick tunnel URL 重启后变了

这是 quick tunnel 的正常行为。需要稳定 URL 时，请配置 named tunnel 和自有域名。

Tailscale 的 100.x.x.x 地址不通

确认 PC 和 iPhone 都已登录同一个 Tailscale 账号，并且 Tailscale App 处于连接状态。

朋友的 iPhone 是否需要额外安装东西？

Cloudflare Tunnel 不需要；Tailscale 需要安装并登录 Tailscale App。

远程访问安全吗？

请保护好 Hermes Agent API Key。不要公开分享 quick tunnel URL。Cloudflare Tunnel 和 Tailscale 的安全模型不同，请根据自己的隐私需求选择。

什么时候应该关闭远程访问？

测试结束后关闭 cloudflared 或断开 Tailscale，可以立即停止对应远程访问路径。
