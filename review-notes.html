English Notes

Hermes Mobile is an iOS mobile control surface for a user-hosted Hermes Agent. The Hermes Agent runs on the user's own computer or server and exposes an OpenAI-compatible Gateway API. Hermes Mobile does not host user conversations and does not proxy traffic through Hermes Mobile developer servers.

Why the App Uses App Transport Security HTTP Exceptions

Hermes Mobile connects to user-hosted Gateways. A user Gateway may be:

  • A LAN IP address such as http://192.168.x.x:8642.
  • A VPN address such as Tailscale http://100.x.x.x:8642.
  • A user-managed HTTPS hostname such as https://agent.example.com.

Some self-hosted LAN and VPN setups only provide HTTP. The app enables ATS compatibility so users can connect to their own private-network Hermes Agent. User chat data is never routed through Hermes Mobile developer servers.

Tailscale and Remote Access

Hermes Mobile does not bundle Tailscale and does not share user identifiers with Tailscale. Tailscale is an optional user-managed network path. Users can also use LAN, Cloudflare Tunnel, or another self-managed Gateway.

Hermes Mobile Bridge

Hermes Mobile Bridge is an optional open-source PC-side helper for pairing and diagnostics:

<github-bridge-url-placeholder>

The app does not require Bridge. Users may manually enter Gateway URL and API Key.

Multi-Agent Routing Status

Hermes Mobile v1.0 focuses on the main Hermes Agent path. Experimental multi-agent routing scaffolding may exist in development builds, but production submission should keep Codex / Claude Code worker routing hidden or disabled unless the PC-side Hermes Agent implementation is ready.

Privacy Summary

The app stores configuration and conversation history locally on the user's device. Chat requests go directly to the user's configured Hermes Agent. Hermes Mobile developer servers do not receive chat content, Gateway URL, API Key, or attachment content.
