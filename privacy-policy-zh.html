Hermes Mobile 隐私政策

最后更新：2026-06-10
适用版本：v1.0 起
联系邮箱：2922062699@qq.com

1. 总览

Hermes Mobile 是一个 iOS 移动控制台，用于连接用户自己部署的 Hermes Agent。Hermes Mobile 的设计原则是：聊天内容、Agent 响应、API Key 和 Gateway 配置由用户自己控制，不经过 Hermes Mobile 开发者运营的服务器。

本政策说明 Hermes Mobile App 本身如何处理数据。用户自行部署的 Hermes Agent、Bridge、VPN、Cloudflare Tunnel 或其他第三方网络服务，可能有自己的数据处理方式。

2. 我们如何收集和使用数据

2.1 App 不收集的内容

Hermes Mobile App 不会将以下内容发送到 Hermes Mobile 开发者服务器：

  • 用户聊天内容。
  • Agent 回复内容。
  • Hermes Agent Gateway URL。
  • Agent API Key。
  • Bridge API Key。
  • 会话历史。
  • 文件或图片附件内容。
  • 用户通讯录、位置、麦克风数据或广告标识符。

Hermes Mobile 当前不使用 IDFA，不做广告追踪，不将用户数据出售给第三方。

2.2 可能收集的匿名诊断数据

如果用户安装的版本启用了 Apple、Expo 或运行时平台提供的崩溃诊断能力，可能会产生以下匿名或低识别性数据：

  • 崩溃日志。
  • 基础设备型号。
  • iOS 版本。
  • App 版本。
  • 性能或启动失败诊断。

这些数据仅用于定位崩溃和提升 App 稳定性，不用于广告追踪。若正式版本未启用崩溃上报，则 App Store Connect 的 App Privacy 表单应按实际上报能力填写。

3. 数据流向

3.1 聊天数据

用户在 Hermes Mobile 中发送的聊天请求会从 iPhone 直接发送到用户配置的 Hermes Agent Gateway。该 Gateway 通常运行在用户自己的电脑、局域网、VPN 网络或用户自行配置的 HTTPS Tunnel 后面。

Hermes Mobile 开发者不会代理、存储或读取这些聊天内容。

Hermes Mobile 会在用户设备本地保存必要的配置和会话数据，用于提供会话恢复、历史记录和连接设置功能。用户可以通过卸载 App 删除 iPhone 上的本地数据。

3.2 远程访问场景

用户可以选择局域网、Tailscale、Cloudflare Tunnel 或其他自有网络方案访问 Hermes Agent。此类网络链路由用户自己配置并承担相应隐私和安全责任。

如果用户使用 Tailscale，流量由用户自己的 Tailscale 网络处理。

如果用户使用 Cloudflare Tunnel，Cloudflare 可能会处理连接 metadata，并在其边缘网络中处理 HTTPS 连接。该方案不是 Hermes Mobile 开发者托管的服务。

4. 第三方服务

Hermes Mobile 使用以下技术或可能与以下服务配合使用：

  • Expo / React Native：用于构建 iOS App。
  • Apple iOS / App Store / TestFlight：用于安装、分发和系统权限。
  • Tailscale：用户可选的远程访问网络，不由 Hermes Mobile 打包或托管。
  • Cloudflare Tunnel：用户可选的 HTTPS Tunnel，不由 Hermes Mobile 开发者强制使用。
  • 用户自己的 Hermes Agent、Hermes Mobile Bridge 和 LLM Provider。

这些第三方服务可能有自己的隐私政策。用户应自行确认其网络和 Agent 部署方式。

5. 用户权利

用户可以：

  • 卸载 Hermes Mobile，以删除 iPhone 本地 App 数据。
  • 在 Hermes Mobile 设置中修改或清空 Gateway URL / API Key。
  • 在 PC 端 Hermes Agent 中清理或删除本地会话、日志和长期记忆。
  • 在 Tailscale、Cloudflare 或其他第三方服务中删除相应网络配置。
  • 通过 2922062699@qq.com 联系开发者，询问隐私政策或 App 数据处理问题。

6. 安全措施

Hermes Mobile 不托管用户的 Agent 服务。用户应自行保护：

  • Hermes Agent API Key。
  • Bridge API Key。
  • PC 端文件系统和项目目录权限。
  • VPN / Tunnel 访问权限。
  • 长期 Memory 数据。

Hermes Mobile 会将当前会话的临时上下文分开管理；Hermes Agent 的长期记忆可能跨会话使用，用于提供连续体验。用户可在 Hermes Agent 侧管理或清除长期记忆。

7. 儿童保护（COPPA）

Hermes Mobile 面向个人开发者、研究者和高级用户，不面向 13 岁以下儿童。我们不会有意收集儿童个人信息。

8. 政策变更

我们可能会随 App 功能变化更新本政策。若数据处理方式发生重大变化，我们会在 App Store 页面、项目文档或 App 内入口中更新说明。
